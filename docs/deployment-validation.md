## 已准备的可审阅内容

- 官方 Python 3.12 基础镜像与官方 Caddy 镜像，均锁定本次实际拉取的摘要。
- 非 root 应用镜像、只读根文件系统、私有数据卷、健康检查、受限临时目录和日志轮转。

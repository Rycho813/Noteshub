## 技术方案与兼容性

保留 Markdown、V2 图片归档及腾讯 OCR、V3 多图与离线同步、电脑本地 OCR 队列、图片查看器、30 条分页阅读和多行保存。删除后的跳转使用现有 `?note=ID`，分页自动定位并滚动到下一条；无下一条则取上一条。删空后仍能快速记录；成功导入过 Markdown 的书仍不能重复导入。

数据库从 v6 **增量升级到 v7**，在单个 SQLite 事务内仅增加：

| 新表 | 目的 |
| --- | --- |
| `deleted_entities` | 保存类型、ID、删除时间，拒绝离线旧副本重新创建已删除的书籍/记录，不保存笔记正文 |
| `retained_files` | 保存单条删除后原图的路径、所属书籍、校验值、大小，纳入备份及后续整书清理 |

既有表和索引不重建，v1–v6 的既有升级链保留。无需重新导入文字/图片或初始化账号。删除 ID 是防重放元数据，不是可恢复内容或回收站。

### 删除边界

| 操作 | 清理 | 保留 |
| --- | --- | --- |
| 单条 Markdown 笔记 | 当前笔记行 | 同书其他笔记、导入记录、Markdown 源文件 |
| 单条图片归档笔记 | 当前正式笔记行 | 原始图片、来源草稿和识别历史；原图标记为保留，禁止旧草稿取消/批量清理误删 |
| 单条纸书记录 | 当前笔记、图片页序、同步回执、识别任务及领取回执等关联行 | 全部尚未清理的原图，包括已移出当前页序的原图，通过 `retained_files` 保留 |
| 整本书 | 该书全部笔记、导入/预览、草稿及其 OCR、纸书任务/回执/页序/图片元数据、保留原图索引，以及明确归属该书的源文件/图片 | 其他书籍、账号、会话、工作区和电脑 OCR 凭证；外部备份和设备本地副本 |

已按原有确认计划清理的纸书图片不会被恢复。单条删除保留的原图目前没有独立图片浏览入口，可以随完整备份保留；V2 来源草稿仍能查看，人工重新归档可能产生一条新笔记。删除 ID 阻止原记录 ID 的离线重放，不禁止用户主动新建另一条记录。

整书文件删除只处理严格白名单路径，拒绝符号链接和跨书引用；外键删除顺序包含 `paper_worker_claims → paper_ocr_jobs` 和纸书附属表。文件先在原目录改名为 `.deleting`，提交失败按数据库引用恢复，提交成功后清理；启动和定时任务补偿重试。数据库与文件系统并无共同原子提交，磁盘/权限持续故障可能延迟恢复，返回 503，不虚报成功。

图片/原文件读取与文件改名使用同一 SQLite 写锁。笔记删除与同步/任务完成串行，晚到的旧任务不会重建记录。已经发往外部 OCR 的调用无法通过本地删除撤回；本次测试未调用付费 OCR。

## 主要变更

- `noteshub/deletion.py`：新增 v7 迁移、三类笔记关联清理、原图保留和文件删除协调。
- `db.py`：保留全部旧迁移，增加 v7；扩展三类文件目录的中断恢复，图片清理识别保留索引；提供 Windows 可运行的目录同步包装，Linux 保留目录 fsync。
- `paper.py`：删除 ID 防重放，保留 CAS/同步回执逻辑；图片读取与删除互斥。
- `web.py`、`drafts.py`、`local_jobs.py`：删除路由、读取锁和保留原图保护，不撤回原有入口/队列功能。
- `maintenance.py`：支持 v7，备份包含保留原图并去重；`retire_drafts.py` 跳过保留来源，修复 Windows SQLite 连接关闭。
- 书籍及阅读模板：保留快速记录和分页，增加删除确认；确认文字说明原图、OCR 与离线副本边界。
- `tests/test_deletion.py`：将旧删除测试适配分页及 v7；`test_integration.py`：混合数据、升级、回滚与原图专项；既有测试更新版本断言、关闭 SQLite 句柄及明确平台跳过。
- `tests/browser_deletion.py` 适配分页；`browser_unified.py` 使用运行脚本的 Python、显式关闭测试 SQLite；本地 OCR worker 显式 UTF-8 读取 JSON。

## 回滚方案与限制

**禁止在 v7 数据上直接运行 `4166517` 或 `7d086c0`**：旧程序不支持 v7，后者甚至不支持图片/纸书结构。不要改低 `user_version` 冒充回滚。旧删除开发报告中的“无需迁移/仅切旧镜像”操作不适用于此整合版。

回滚以升级前完整备份恢复到新项目/新空卷，再配旧镜像验证；示意（填真实路径、标签并确认端口未占用）：

```bash
cd /opt/noteshub
sudo sha256sum -c /var/backups/noteshub/实际升级前备份.tar.gz.sha256
sudo env COMPOSE_PROJECT_NAME=noteshub-integration-restore NOTESHUB_HTTP_PORT=18000 NOTESHUB_IMAGE_TAG=before-integration-实际时间戳 bash scripts/restore.sh /var/backups/noteshub/实际升级前备份.tar.gz
sudo env NOTESHUB_HTTP_PORT=18000 NOTESHUB_IMAGE_TAG=before-integration-实际时间戳 docker compose -p noteshub-integration-restore up -d --no-build app
```

沿用原生产 OCR overlay/凭证参数；恢复项目必须是新项目，既有同名卷时另选名称，不删除正式卷。核对书籍、文字、图片、导出后另行确认切换入口。升级后产生的写入不会自动并入旧快照，须在回滚前保留 v7 完整备份并评估差异。离线设备仍有副本，恢复前快照可能没有新增删除 ID，应将旧副本重放影响纳入回滚评估。

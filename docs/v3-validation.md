## 容器与数据兼容性

实际本地 Docker、单 worker、UID 10001、loopback 18080、测试卷/项目及受限资源配置。由真正的旧 v3 数据库和旧镜像启动，完整备份校验后才迁移到 v6。旧账号文件、图片文件、源 Markdown 摘要与原字段保持不变；原文 137 字、一读 17 字、一次成功 OCR 记录保留。验证 V2 幂等归档以及新增多图记录、本地任务协议、整书导出、备份恢复到独立空卷和重启。

容器里的本地 OCR 结果是合成结果；真实模型在独立 Python 进程中运行，其端到端浏览器测试独立验证。服务器镜像依赖清单与 V2 一致，不包含 RapidOCR、ONNX Runtime 或 Paddle 推理服务。

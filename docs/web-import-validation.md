# Web 登录、书籍与导入阶段报告

> 本文保留该阶段完成时的结果；当前二读和导出进展见 [后续阶段报告](review-export-validation.md)。

## 完成范围

- FastAPI + Jinja2 + 原生 HTML 表单，无前端框架或 JavaScript 依赖。
- 单用户交互创建账号、scrypt 密码哈希、数据库会话、CSRF、防暴力尝试、退出及会话过期。
- SQLite schema v1：书籍、笔记、成功导入、临时预览、会话。使用标准库 sqlite3，所有连接开启外键。
- 书籍列表、新建、书名搜索、导入后的原文/一读评述只读查看。
- UTF-8 Markdown 上传（2 MiB 上限）、服务器保存预览、异常完整内容/行号显示、手动修正、整批确认、取消。
- 每书仅一次成功导入：同文件、不同文件和并发确认均不能追加或覆盖已有笔记。
- 仅成功源文件长期保存于私有目录，可通过认证下载原始字节；不提取 Zotero 定位链接。

暂未实现二读编辑、状态操作、整书导出、照片/OCR、Docker 和腾讯服务器部署。页面中的进度为已有笔记状态统计，本阶段新笔记均为待处理。

## 验证方法

在项目根目录：

```bash
.venv/bin/python -m unittest discover -v
.venv/bin/python -m pip check
```

共 **52 项测试通过，无跳过**：保留原解析器 32 项，新增 Web/持久化/认证测试 20 项。测试在隔离临时数据目录创建测试账号，未给用户数据目录设置默认密码。

重点验证：

- 未登录不能读取书籍、预览和源文件，也不能修改或确认。
- 登录及写操作均需要有效 CSRF；默认会话 Cookie 包含 Secure、HttpOnly、SameSite=strict。
- 连续失败登录触发短时暂停；退出和过期会话失效。
- 真实《论爱欲.md》预览 154 条、异常 7 条；伪造客户端确认标志无法入库，局部修正仍无法入库。
- 使用**测试专用的模拟人工修正文本**填写 7 个异常后，整批写入 154 条，修正标记为 7 条，源文件字节不变。这不是替用户决定真实评述。
- 重复上传、重复确认、两线程并发确认均不增加重复数据。
- 模拟第二条笔记写入失败：已插入的第一条、导入记录和源文件全部回滚/清理，预览保留以便重试。
- 模拟磁盘同步失败：无正式笔记或源文件残留。
- 无效编码、空文件、错误扩展名、过大文件、超限分块请求均受控拒绝。
- 取消、替换、退出、过期清理临时预览；其他登录会话不能访问本次预览。
- 重建应用后书籍、笔记、会话及成功源文件仍可使用；启动清理意外中断留下的孤立源文件。
- 用户标题、上传内容及人工修正中的 HTML 按纯文本转义，数据库保存文字本身。

当前运行环境的沙箱会使最小 FastAPI TestClient 的线程事件循环挂起；在允许本机通信的执行上下文中完整测试通过。不是通过跳过测试或禁用校验处理。

## 实际浏览器检查

可选脚本：

```bash
python3 tests/browser_smoke.py
```

脚本要求运行它的 Python 已安装 Playwright（本次为 1.62.0），系统有 Chromium，并已创建项目 `.venv`。它只启动本机临时服务，使用随机测试密码和临时数据库，结束后停止服务并清理数据；不连接腾讯服务器或外部网站。

实际检查流程：

1. 桌面 1280×900：登录 → 新建书籍 → 上传真实样本 → 确认按钮不可用 → 逐条填写并保存 7 个模拟修正 → 确认 154 条入库 → 本书不再提供上传操作。
2. 手机尺寸 390×844：登录 → 新建书籍 → 上传含异常的测试文件 → 检查输入框中的开头换行没有被浏览器吞掉 → 取消上传 → 退出。
3. 两种布局没有横向溢出；桌面无页面脚本错误；最终数据库恰好有 1 次成功导入、154 条笔记和 0 个临时预览，成功源文件恰好 1 个。

截图写入被 Git 忽略的 `test-results/desktop-preview.png` 和 `test-results/mobile-preview.png`。已查看截图，确认异常说明、原始内容和编辑框在桌面与手机尺寸正常展示。

这是 Chromium 的真实浏览器操作与移动尺寸模拟，**不等同于真实 iPhone Safari 或 Windows 实机验收**。

## 运行与数据维护

完整首次安装、账号创建、启动命令及配置见 [README](../README.md)。账号初始化和服务启动须使用同一个 `NOTESHUB_DATA_DIR`。

临时预览从上传起 1 小时过期；后台每分钟清理，启动和访问相关页面也清理。浏览器关闭不会可靠地通知服务器，不能依靠关页立即删除。成功确认后删除该书所有临时预览；失败的确认保留当前未到期预览供重试。

备份时停止应用后完整复制数据目录，包含账号、SQLite 和成功源文件。当前测试已验证重建应用后持久化，不将其表述为腾讯服务器部署或异机灾备演练完成。
